macOS Finder의 컬럼 보기 방식이에요. 경로 전체가 왼쪽에서 오른쪽으로 펼쳐지고, 오른쪽 패널에서 고른 폴더의 사진과 장수를 미리 봐요. 키보드로만 조작할 수 있어요.

세 시안 공통 규칙

  • 체크 = 하위 폴더까지 포함. 일부만 선택되면 상위 체크박스에 – 표시가 떠요.
  • 사진이 직접 들어 있는 폴더(예: 손 42장 + 하위 쥐는 손)는 "이 폴더 이미지만" 따로 고를 수 있어요.
  • 장수는 항상 하위 포함 합계로 보여 주고, 시작 버튼에 선택한 총 장수를 표시해요.
  • 폴더 등록은 + 버튼과 드래그 앤 드롭 둘 다 지원해요.
